What stays in this browser

Local storage, and nothing else

No account, no server, no cookies

The game keeps two notes in your browser's localStorage so the next round can mix in questions you have already seen and compare how you read them. That data never leaves this browser.

seenQuestions

A list of question ids from rounds you finished. The game uses it to prefer unseen questions and to bring a few familiar ones back. It does not store the question text, your answer, or whether you were right.

Example: [100, 130, 241]

feedbackAttemptHistory

Up to the last 240 answers, saved only when a round ends. Each entry is the intent that was correct, the intent you picked, whether that pick counted, and whether the line was marked as a problematic pattern. There is no name, timestamp, or question text.

Example:

[
  {
    "correct": "Coaching",
    "selected": "Advice",
    "accepted": false,
    "isEvil": false
  }
]

The results page uses this to say which intents are holding steady across rounds. One round is not enough for that comparison, so the first game only reports what happened in that game.

What is not stored

  • Nothing is sent to a server. Hosting this site does not receive these keys.
  • No cookies, accounts, or analytics identifiers are set by the game.
  • Answers from a round you leave unfinished are not saved.

How to remove it

Clear site data for this origin in your browser, or use the button. It only removes the two keys this game writes.

localStorage.removeItem('seenQuestions');
localStorage.removeItem('feedbackAttemptHistory');

Clearing it resets spaced repetition and the across-rounds summary. The question bank itself is unchanged.
